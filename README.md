## ⚡ About Me

I am a Software Engineer who prioritizes **maintainability, scalability, and architectural clarity**. My experience ranges from crafting distributed backend systems and high-throughput REST APIs to delivering headless content management solutions and fluid mobile experiences.

- ⚙️ **Backend & Systems**: Engineering scalable services using **Go**, **.NET 8 / C#**, and **Node.js** with Clean Architecture and SOLID principles.
- 🧩 **CMS & Headless Ecosystem**: Building structured, customizable, and headless content backends with **Strapi** and **WordPress** (REST/GraphQL integration).
- 📱 **Mobile Engineering**: Developing cross-platform apps using **Flutter & Dart** with scalable state management (**GetX / Bloc**) and seamless API synchronization.
- 🗄️ **Data & Messaging**: Managing relational schemas, ACID transactions, and caching/queues with **PostgreSQL**, **Redis**, and **RabbitMQ**.
